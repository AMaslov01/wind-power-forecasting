# Инструкция по созданию публичного репозитория и пакета сдачи

## 1. Что должно быть в GitHub

В публичный GitHub коммитим только воспроизводимый код и документацию:

```text
README.md
run_solution.sh
docs/FINAL_SOLUTION_NOTE.md
docs/REPOSITORY_INSTRUCTIONS.md
dataset/README.md
physics/
catboost_pure/                 # можно оставить как baseline/архив, не основной путь
```

Не коммитим:

```text
dataset/*.csv
model_weights/
outputs/
deliverables/
physics/predictions*.csv
physics/oof_*.npz
catboost_info/
.venv/
```

Эти пути уже закрыты в `.gitignore`.

## 2. Проверка перед публикацией

```bash
bash run_solution.sh --check-only
bash run_solution.sh
```

Ожидаемые файлы:

```text
outputs/predictions_q1.csv
outputs/predictions_may18.csv
outputs/RUN_REPORT.json
```

## 3. Создание публичного GitHub

Создать пустой публичный репозиторий на GitHub без README/license/autogenerated
files, затем:

```bash
git remote -v
git remote set-url origin https://github.com/<USER>/<PUBLIC_REPO>.git
git add .gitignore README.md run_solution.sh docs dataset/README.md physics catboost_pure
git commit -m "Prepare one-command final wind forecast solution"
git push -u origin codex-v9-regime-first
```

Если нужно публиковать из ветки `main`:

```bash
git checkout -b main
git push -u origin main
```

Важно: не вставлять GitHub token в notebook/README/command. Если нужен private
push, использовать GitHub CLI или credential manager.

## 4. Что положить в ZIP/локальную папку

ZIP должен дублировать GitHub и дополнительно содержать:

```text
dataset/train_dataset.csv
dataset/valid_features.csv
dataset/3888f9f2-9bda-4b2c-94af-5562668bce86_test_dataset.csv
model_weights/
outputs/predictions_q1.csv
outputs/predictions_may18.csv
reports/solution_note.txt
DATA_MANIFEST.txt
```

Готовая локальная папка уже собрана:

```text
deliverables/final_solution_v14_nocds/
```

Проверка изнутри этой папки:

```bash
cd deliverables/final_solution_v14_nocds
bash run_solution.sh --check-only
bash run_solution.sh
```
